Project Introduction

This project is using the US Superstore Data from this Kaggle data set. I picked this data set because an customer choices and online shopping has become an interest of mine since more and more people prefer online shopping to traditional, brick-and-mortar physical store shopping.

This document explores the US Superstore data and looks at how sales, profits, and discounts vary across product categories, customer segments, and regions. This Quarto Document will later be converted into a Shiny App!

# Classify each order line as profitable, a loss, or break-even.
# Count these outcomes within each product category.
category_profit_counts <- superstore |>
  mutate(
    profit_status = case_when(
      is.na(profit) ~ "Missing",
      profit > 0 ~ "Profit",
      profit < 0 ~ "Loss",
      TRUE ~ "Break-even"
    )
  ) |>
  count(category, profit_status, name = "order_lines") |>
  pivot_wider(
    names_from = profit_status,
    values_from = order_lines,
    values_fill = 0
  )

Revenue and profit summaries

# Means, medians, and standard deviations describe profit per order line.
category_performance <- superstore |>
  group_by(category) |>
  summarise(
    units_sold = sum(quantity),
    total_revenue = sum(sales),
    total_profit = sum(profit),
    mean_profit = mean(profit),
    median_profit = median(profit),
    sd_profit = sd(profit),
    .groups = "drop"
